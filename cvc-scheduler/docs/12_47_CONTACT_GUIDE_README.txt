PROJECT LOCAL — ILLUSTRATED CONTACT GUIDE
========================================

This is a standalone static guide for project contacts. It includes the approved
Project Local logo, favicon, social preview, full-resolution screenshot viewer,
mobile sidebar, scheduling tabs, print styling and carefully selected demo
screenshots from the uploaded development-review previews.zip.

DEPLOY / PREVIEW
---------------
The approved guide is already included in the app's public/guide/ folder.
Preview it through the local Next.js server at /guide to verify the canonical
rewrite, assets, navigation and browser behavior. When deployed, its URL is:

  https://projectlocal.app/guide

The guide does not read or write production data.

RELEASE AND PRIVACY REMINDERS
----------------------------
Screenshots show reviewed preview builds, not verified live production screens.
Verify button labels, functionality, permissions, Communications templates,
name lookup and project-photo backups against the DEPLOYED app before this
guide is distributed. The guide describes the current beta's personalized
volunteer email-link access, not unverified public name lookup.

Noindex metadata discourages indexing but DOES NOT protect the page. Anyone
with its URL can access it. Publish only if all screenshots contain sanitized
sample data and the current product's release checks have been completed.
