## Technical constraints versus policy
Technical: previously downloaded files cannot be revoked; a forwarded bearer does not identify its human holder; private storage metadata alone does not recover bytes; Vercel payload limits constrain the proposed gateway; document parsing requires isolation; project selection is not authorization. These cannot be approved away by a label.

Policy: who publishes, which exact people/classes get a file, after-assignment access duration, stronger-security login requirements, retention and budget are coordinator decisions. The proposed defaults are intentionally explicit but are not implemented.

## Approval blockers
The five source PDFs are missing, so invitation extraction, exact map comparison, sensitive-content review and publishable version selection cannot be verified. Existing provider/account quotas and processing host pricing are unverified. C4 individual identity assurance is not implemented today. Complete object restore is not proven today. No instruction to implement should be inferred until these decisions and source review are resolved.
